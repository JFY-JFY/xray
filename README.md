# X-RAY 财富透视局

> 看得懂的公司，才值得你下注
>
> HACKATHON DEMO · 2026 ｜ 杭州银行赞助课题

一款运行在浏览器里的 **3D 金融投资博弈游戏**。你是这座金融城的**首席投资官**，掷骰巡城，遇到公司先看它的资料，再决定要不要掏钱。游戏的真意不在于掷骰运气，而在于训练一套判断公司真伪的方法——**照毛利率、验现金流、查增长、挑红黄绿、判结论**。

---

## 快速开始

```bash
# 方式一：直接双击
xray.html

# 方式二：起个本地服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080/xray.html
```

- **零依赖、零构建**：three.js 已内联进单文件，全程离线可玩，不需要 npm / 打包 / 服务器。
- 建议使用 Chrome / Edge 等支持 WebGL 的现代浏览器，并开启硬件加速。

## 一、游戏目标

4 位投资人（你 + 3 位 AI）在同一座城里行动，**20 回合**后总资产最高者成为"金融城之王"。

总资产 = 现金 + 公司估值 + 储蓄 + 持仓市值

公司估值会随**等级**提升而放大；已"爆雷"（doomed）的公司估值只剩 35%。

---

## 二、一回合的流程

```
掷骰（1~6 点） → 按方向逐格移动 → 落地结算 → （可选）布陷阱 → 结束回合
```

每轮四位玩家依次行动，全部走完进入下一回合；每回合结束后会结算：

- **爆雷判定**：每家已持有的公司有 16% 概率爆雷，损失 15 万，公司转为无主
- **储蓄利息**：储蓄余额的 5%
- **持仓市值波动**：-12% ~ +18% 随机
- **差旅餐费**：每 2 回合扣 6 万；若本回合在餐厅用过餐，则减半为 3 万

## 三、棋盘与格子

棋盘是 **7×7 网格**，正中心的 3×3 是**杭州银行大楼**（单独建模的中央塔楼，不占格子），其余 **48 格**。

> 开局时棋盘布局会**随机打散**，但两处位置恒定：启动格与中心的杭州银行大楼。
> 你越有钱，杭州银行周围的楼就越密、越高。

| 类型 | 数量 | 落地效果 |
|---|---|---|
| `start` 启动格 | 1 | 停在格上领经营红利 +10 万 |
| `center` 杭州银行 | 1 | 领取财富礼包 10~18 万 |
| `company` 公司 | 24 | 无主可收购；自己的可增资升级；他人的需付分红 |
| `save` 储蓄 | 7 | 判断后存入，金额 ×1.2 |
| `stock` 股票 | 6 | 判断后建仓，金额 ×1.35 |
| `rule` 监管 | 6 | 金融监管局合规问询 |
| `chance` 市场风向 | 1 | 随机抽取一张风向卡（-11 ~ +15 万） |
| `risk` 风险 | 1 | 缴纳手续费 5~6 万 |
| `event` 事件 | 1 | 全城事件，所有投资人共同承担 |

**移动规则**：只能沿上下左右走，**不能走回头路**；若走进死胡同（四周全是走过的格子），则允许**原路返回**，保证剩余步数一定能走完。

## 四、公司：看资料，再掏钱

每家公司都有一份 **X-RAY 档案**，五个维度：

| 字段 | 含义 | 字段 | 含义 |
|---|---|---|---|
| `g` | 营收增速 | `c` | 现金流 |
| `m` | 毛利率 | `f` | 风险提示 |
| `d` | 负债率 | `bld` | 建筑形态（决定外观与用途） |

查看资料后三选一：

| 动作 | 公司为真 | 公司为雷 |
|---|---|---|
| **投资** | 赚 **35%** | 亏 **60%**，并标记为 doomed |
| **举报** | 误报罚 **8 万** | 奖励 **15 万**，公司被监管查封 |
| **放弃** | 扣手续费 2 万 | 扣手续费 2 万 |

**增资升级**：已持有的公司可花钱升级（费用 = 价格 × 50%），共 3 级（初创 → 成长 → 旗舰），等级越高分红越高。

**分红**：踩到他人公司时支付 `租金 × (1 + 0.6 × (等级-1))`。

**风险陷阱**：在自己的公司布设陷阱需 6 万，对手踩到会触发一次额外的防骗问答。

## 五、判断方法：手册五步

游戏内置一本《防骗手册》，也是本作想教会你的东西：

| 步骤 | 口诀 | 要点 |
|---|---|---|
| 01 | **照毛利率** | 毛利率要跟同行比：高得离谱又讲不清为什么，就要警惕 |
| 02 | **验现金流** | 利润 ≠ 真钱。经营现金流要常年为正，并匹配净利润 |
| 03 | **查增长** | 增长要看从哪来：主营变强，还是靠赊账、借款、补贴堆出来 |
| 04 | **挑红黄绿** | 红灯一票否决、黄灯必须求证、绿灯三项齐备才放行 |
| 05 | **判结论** | 三项以上指标互相印证才下手；出现红灯就别自欺欺人 |

**踩雷复盘**：一旦在造假公司上投资，游戏会弹出**五步推导链**，逐条对照你是从第几步开始失守的；终局还会做一次全局复盘，指认你用到了（或忽略了）手册的哪一条。

## 六、操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` 或 `↑` `↓` `←` `→` | 选择前进方向 |
| `空格` | 掷骰子（漫游时为跳跃） |
| `1` `2` `3` | 问答时选择第 1/2/3 个选项 |
| `V` | 开启 / 关闭自由漫游 |
| `F` | 跟随视角 |
| `H` | 打开 / 关闭防骗手册 |
| `Q` / `E` | 折叠左侧 / 右侧面板 |
| `Esc` | 关闭当前浮层 |

> 移动时右下角会**实时列出这一步可走的方向**（如 `⌨ 可走方向 ↑ →（还剩 2 步）`），按列出的方向即可。
> 鼠标操作同样支持：拖拽旋转视角、滚轮缩放、点击方向盘箭头。

## 十、项目结构

```
xray.html      # 全部内容：HTML + CSS + 内联 three.js + 游戏逻辑（单文件，约 863 KB）
README.md
```

单文件内以 `/* ===== @ xray-xxx ===== */` 注释划分功能模块：

| 模块 | 职责 |
|---|---|
| `@ xray-bank-core` | 杭州银行中央大楼建模与"杭州银行"标牌 |
| `@ xray-shuffle` | 开局棋盘随机打散（锚定启动格与银行中心） |
| `@ xray-manual` | 防骗手册（五步准则）与关键词高亮 |
| `@ xray-derive` | 踩雷五步推导链、终局复盘 |
| `@ xray-five-step` | 五步推导的展示与对照 |
| `@ xray-slides` | 开局教学幻灯片 |
| `@ xray-learn` | 判断学习记录与命中率统计 |
| `@ xray-demo-mode` | 演示局（8 回合）模式 |
| `@ xray-hud-fold` | HUD 面板折叠（Q / E） |
| `@ xray-mapcolor` | 小地图配色 |
| `@ xray-label-dim` | 顶牌压暗，避免撞色影响可读性 |
| `@ xray-glow-near` | 近距离辉光 |
| `@ xray-light-01` / `@ xray-build-03` | 光照与建筑生成 |

核心状态集中在全局对象 `W`（回合、位置、所有权、等级、陷阱、查封、爆雷等），棋盘数据为 `vt`（48 格）、邻接表 `mc`、世界坐标 `Tt`。

## 十一、近期修复记录

| 问题 | 原因 | 处理 |
|---|---|---|
| 同类公司扎堆 | 规划器按类型连续排布 | 开局随机打散，锚定启动格与杭州银行中心 |
| 部分公司无法收购 / 显示"他人持有" | 所有权等状态数组长度 24，而棋盘 48 格，高索引公司读取为 `undefined` | 数组长度改为按棋盘实际格数 |
| 部分公司永不爆雷 | 爆雷检测只扫描前 24 格 | 扫描全部格子 |
| 步数未走完却卡住 | 禁止回头路导致进入死胡同后无格可走 | 无新路口时允许原路返回 |
| 不知道该按哪个方向 | 提示只写死"按 W/A/S/D" | 提示实时列出当前可走方向 |
| 金额显示 `¥NaN万` | 分红计算读取越界的 `W.level`，`undefined - 1` 产生 NaN | 越界处加兜底；`Nt()` 拒绝非有限金额并自动归零自愈 |

## 十二、技术说明

- **渲染**：three.js（已内联），WebGL，OrbitControls 相机；支持阴影、辉光、粒子。
- **无外部请求**：不加载任何 CDN 资源，完全离线。
- **存档**：无后端，游戏状态只存在于当前页面内存，刷新即重开。
- **音效**：Web Audio API 程序化合成（可右上角静音），无音频文件。
